# Student Marks Analyzer (Java)

A simple Java project that analyzes student marks from a CSV file.

## Features
- Reads student marks from a dataset
- Calculates average marks
- Finds the topper student
- Counts pass and fail students
- Assigns grades based on marks

## Technologies
- Java
- CSV File Handling

## How to Run
1. Compile the program

javac StudentMarksAnalyzer.java


2. Run the program

java StudentMarksAnalyzer
